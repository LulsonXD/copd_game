# Путь дыхания — COPD Gamified Digital Health PoC

Визуальная версия приложения на Streamlit + SQLite.

## Запуск
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Возможности
- COPD-миссии: реабилитация, знание дня, самонаблюдение, задача недели;
- XP, уровни и внутриигровые монеты;
- персонаж с меняемой одеждой;
- магазин косметических предметов;
- комнаты и локации;
- постоянное хранение покупок, экипировки и прогресса в SQLite;
- встроенная SVG-графика без внешних библиотек.

`assets/ui_concept_reference.png` — визуальная референс-композиция концепта.

Тайминги и содержимое тренировочного сценария в PoC демонстрационные и не являются индивидуальным медицинским назначением.
